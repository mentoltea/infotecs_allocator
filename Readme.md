Функции `malloc` и `free` объявлены в [allocator.h](./allocator.h)

Они базируются на системе страниц, призванной минимизировать обращения к системным вызовам. В качестве стратегии выбора свободного места в памяти страницы (и между страницами) для борьбы с дефрагментацией выбрана стратегия минимального по размеру подходящего пространства. [page.h](./page.h).

Имплементация аллокации и освобождения памяти работает для Win32 и Unix/Posix систем (протестировано на Windows 10 и Ubuntu 22.04). [base.h](./base.h)

В коде по мере необходимости оставлены комментарии, базово описывающие функции (в случаях, когда это не понятно из названия) и логику кода.

## Зависимости
- `<stdint.h>` (определения типов и их макс значения)
- `<stdbool.h>` (bool, true, false)
- `<string.h>` (memcpy)
- `<pthread.h>` (pthread_mutex)

В проекте использовался также [darray.h](./darray.h) - набор макросов для работы с динамическими массивами из моего стороннего проекта [cutils](https://github.com/mentoltea/cutils), однако он целиком встроен в проект, поэтому в список сторонних зависимостей не включён.
